# tools — allumage et extinction de l'environnement AWS

Scripts Bash ([D11](../docs/decisions/D11-iac-allumage-cout.md)), lancés sous Git Bash par `bash tools/<script>.sh`. Prérequis : AWS CLI, Terraform 1.14.5, `jq`, `curl`, `openssl`, `iconv` et `base64` (fournis par Git Bash) ; `kubectl` et Helm ; `python3` ou `python` (archive de la sonde Lambda), Docker (Trivy) et `gh` (journaux de la CI) pour le contrôle après déploiement. Profil `collector-lab` à jour après « Start Lab », jamais d'identifiant en argument ni dans le dépôt.

| Script | Rôle |
|---|---|
| `bootstrap.sh` | Une fois, rejouable sans effet (AC1) : bucket des photos en CLI, puis `infra/persistant` (zone, certificat, budget, configuration du bucket, groupes de journaux) ; refuse tout plan qui détruit ou remplace ; affiche la délégation à poser dans Cloudflare |
| `up.sh --fin-lab HH:MM [--sans-flux] [--repetition-soutenance]` | Contrôles (seuil de coût G5 en premier, sans appel AWS : refus si le cumul de `couts.csv` atteint 70 % de 50 $, soit 35 $, sauf `--repetition-soutenance` ; identité, région, refus sous 75 min restantes, version EKS, couche persistante, `status.sh --strict` si l'état est vide), purge des photos, `apply` horodaté avec l'ALB fermé, puis aussitôt destruction programmée (G1) et rappel du poste (G7), même si l'`apply` a échoué ou a été interrompu (piège `EXIT`, Ctrl-C ou terminal fermé, journal alors écrit dans `tools/.session/armement-sortie.log` ; un armement interrompu est rejoué) ; aucun rappel G7 si l'état ne contient aucune ressource facturable ; kubeconfig, application par `up-flux.sh` (Flux ; `--sans-flux` : helm en direct, filet P1), HTTPS 200, puis contrôle après déploiement (AC11) ; code retour non nul si le contrôle est rouge. `--fin-lab` reprend l'heure du compteur du lab (XP01 X14) ; `--debut-lab HH:MM` reste accepté (lab démarré la veille compris). Une fin de lab à plus de 240 min est refusée (heure mal saisie). Refusé tant qu'un `down.sh` précédent n'a pas abouti ; reprise d'un `up` interrompu : inventaire comparé à l'état, ressources hors état signalées |
| `up.sh --prolonger --fin-lab HH:MM` | Après un nouveau « Start Lab » : purge le groupe de planifications, réarme G1 sur la nouvelle fin et reprogramme le rappel G7 |
| `up-flux.sh --contexte CONTEXTE --valeurs aws\|k3d [--sans-flux] [--rotation]` | US-007, appelé par `up.sh` (aussi seul sur k3d) : empreintes et commit `source` lus sur `env/demo`, chaque image vérifiée par `cosign verify` (identité du workflow de `main`, refus d'une seule image non signée, AC4) et rattachée à son dépôt (`tools/ci/images.txt`) ; NodePorts lus dans Terraform ; namespaces et refus par défaut (`infra/k8s/application.yaml`) ; base amorcée par un Job éphémère (Secret maître supprimé même en échec, MD2) ; Secrets par service, repris s'ils existent (`--rotation` : nouveaux mots de passe des rôles, services redémarrés) ; Flux installé dans `collector` (deux contrôleurs, `Role` du namespace, usurpation du seul `deployeur`, sortie sans IMDS) avec sources épinglées sur les commits vérifiés, attente des `HelmRelease` ; ou `--sans-flux` : `helm upgrade --install` du même chart avec le même fichier d'empreintes (AC6) ; tests de fumée. Sur k3d : `--sans-flux --empreintes FICHIER [--images-locales]` |
| `controle-apres-deploiement.sh` | AC7 à AC9 : TLS (301, TLS 1.0/1.1 refusés, 1.2 accepté, certificat, HSTS) ; X17 (balayage des adresses publiques du VPC depuis le poste ; API, base et ALB vus d'une sonde Lambda éphémère hors plage ; un seul load balancer, aucun Service `LoadBalancer`, NodePorts, règles et groupe de l'ALB, liste blanche XE4/ME8, sortie sans IMDS sur l'union des politiques de chaque namespace par `sortie-sans-imds.jq`) ; X20 (valeurs des secrets de session cherchées dans les états, releases Helm, objets du cluster, journaux du poste et de la CI ; montages de Secrets par pod ; Trivy sur les images et l'IaC ; AMI recommandée). Verdict dans `.session/controle-<session>.json`, rapports masqués dans `docs/mesures/US-004/` |
| `alb.sh ouvrir\|fermer` | AC10 : ouverture à Internet refusée sans verdict vert pour la session et l'état courants ; contrôle rejoué une fois ouvert, fermeture immédiate s'il rougit |
| `down.sh` | Flux en premier, même sans CLI `flux` (`HelmRelease` désinstallées, puis manifeste de session ou regénéré par l'image `flux-cli`), puis releases Helm restantes, vidage des photos, secrets `collector/*` supprimés sans délai, sonde Lambda résiduelle supprimée, `destroy` avec reprise sur les interfaces, groupe de planifications supprimé et attendu jusqu'à disparition (G1), `status.sh --strict` (AC4), ligne de coût et cumul affiché (G5), rappel du poste annulé une fois l'extinction réussie (G7), identifiants du canal (`infra/canal/.genere/`) effacés. Marque la session « extinction incomplète » dès son lancement et ne retire la marque qu'une fois le `destroy` et l'inventaire verts : tout échec bloque le `up` suivant |
| `status.sh [--strict]` | AC5 : session, temps restant, coût estimé de la session et cumul, couche persistante, ressources, nœuds, pods et HPA, dernier verdict du contrôle, inventaire. `--strict` : inventaire strict et dérive de la couche persistante (blocage d'accès public, rétentions), code retour non nul sinon (AC4, MI8) |
| `inventaire.sh [--strict]` | Inventaire du compte indépendant de l'état, hors couche persistante ; moteur de `status.sh --strict` |
| `lib.sh` | Fonctions communes (profil, chemins natifs pour Terraform et les outils Windows, chemin nul natif pour `curl`, `jq` sans retour chariot, car `jq` de Windows termine ses lignes par CRLF (XP01 session 1), masquage du compte et des adresses, zone et certificat persistants, sauvegarde d'état, coût estimé, sonde Lambda, journal de session ; garde-fous de coût testables sans AWS : cibles G1 lues dans l'état, journal et seuil G5, rappel G7) |
| `sortie-sans-imds.jq` | Filtre du contrôle `sortie-sans-imds` : une politique de sortie couvre tous les pods, et aucune règle de sortie du namespace (vide, sans `to`, ou plage couvrant 169.254.169.254 sans l'exclure) ne laisse joindre l'IMDS ; seule exception : la règle vers `169.254.169.254/32` seul d'une politique du namespace `place-de-marche` qui sélectionne `collector/acces-aws: "true"` (US-006 AC5) |
| `tests/sortie-sans-imds.sh` | Cas positifs et négatifs du filtre, sans AWS : `bash tools/tests/sortie-sans-imds.sh` |
| `tests/garde-fous-cout.sh` | US-005 sans AWS : cibles et champs des planifications G1 (état complet, `apply` partiel, clé KMS et bucket jamais ciblés), journal et cumul G5 (CRLF, ligne sans fin), seuil de 35 $ et `--repetition-soutenance`, relecture du `couts.csv` du dépôt (AC8), rappel G7 avec PowerShell et `at` simulés |

Les tests de `tools/tests/` tournent en CI (job « Workflows et scripts »).

**Destruction programmée (G1)** : groupe EventBridge Scheduler `collector`, planifications ponctuelles sous `LabRole`, supprimées après exécution, cibles exactes lues dans l'état Terraform (`terraform show -json`, donc aussi après un `apply` partiel) :

| Échéance | Cible (`aws-sdk:`) | Ressource |
|---|---|---|
| T-30 | `eks:deleteNodegroup` (`ClusterName`, `NodegroupName`) | node group et ses instances, volumes compris |
| T-30 | `rds:deleteDBInstance` (`DbInstanceIdentifier`, `SkipFinalSnapshot`, `DeleteAutomatedBackups`) | RDS, avec son secret géré |
| T-30 | `elasticloadbalancingv2:deleteLoadBalancer` (`LoadBalancerArn`) | ALB |
| T-30 | `ec2:deleteNatGateway` (`NatGatewayId`) | NAT |
| T-10 | `eks:deleteCluster` (`Name`) | cluster et modules complémentaires |
| T-10 | `ec2:releaseAddress` (`AllocationId`) | adresse Elastic IP de la NAT |

Ce qui reste après G1 ne facture pas ou presque (VPC, sous-réseaux, groupes de sécurité, groupe cible, point de terminaison S3 de type passerelle, groupe de journaux du plan de contrôle, enregistrement DNS) et part au `down.sh` suivant. La couche persistante (clé KMS, bucket des photos, zone, certificat) n'est jamais ciblée.

**Rappel du poste (G7)** : 45 min avant la fin du lab, sans privilège. Windows : tâche planifiée de l'utilisateur `Collector-rappel-fin-lab` (`Register-ScheduledTask`, déclenchée au réveil si le poste dormait) qui affiche une boîte de dialogue. Linux : `at` (file `c`) avec `notify-send`, sinon `wall` ; seule la tâche marquée `Collector-rappel-fin-lab` est annulée par `down.sh`. Ni l'un ni l'autre : avertissement, `up.sh` continue.

**`down.sh` doit se terminer avant « End Lab »** : lab arrêté, `LabRole` perd ses droits et la destruction programmée échoue (XP00 S8b). `up.sh` affiche l'heure limite de lancement de `down.sh`.

Traces : phases horodatées dans `docs/mesures/sessions.csv` (X4, X5), coût par session dans `docs/mesures/couts.csv` (G5, sans compte, adresse ni identifiant de session). Fichiers de session et journaux d'`apply` dans `tools/.session/`, copies d'état dans `infra/.etat-sauvegardes/` : ignorés par git.
